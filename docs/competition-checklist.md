# Competition Checklist

- Project identifier: `moonbit-geofield`
- Project name: MoonBit geophysical field toolkit
- License: Apache-2.0
- Main language: MoonBit
- Owner-maintained repository with no generated contributor identities
- Public API documented in `README.mbt.md`
- Design and formula boundary documented in `docs/design.md`
- Interface files generated by `moon info`
- Tests cover gravity, magnetic field, harmonics, grid interpolation, profile sampling, CSV, and GeoJSON helpers
- CI runs formatting, interface generation, strict static checks, tests, and CLI smoke run

## Current Non-goals

- No bundled proprietary or large official geophysical coefficient tables
- No navigation-grade magnetic model claims
- No hidden data source or generated benchmark dataset

## Extension Plan

- Add coefficient loaders for EGM/WMM/IGRF style tables
- Add missing-value policies for grids
- Add contour and raster export utilities
- Split richer IO adapters into optional packages if dependencies grow
