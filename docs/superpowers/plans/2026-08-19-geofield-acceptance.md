# Geofield Acceptance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn `moonbit-geofield` into a tested, reusable MoonBit geophysical field toolkit suitable for hackathon acceptance, with more than 8,000 lines of compilable application source, reproducible benchmarks, and complete CI.

**Architecture:** Keep the root package as the public facade and split implementation into focused files for validation, statistics, raster operations, profiles, filtering, coordinate transforms, coefficient loading, and serialization. Add a small benchmark executable that reports measured operation timings and workload sizes without claiming unmeasured performance.

**Tech Stack:** MoonBit stable toolchain, MoonBit core library, GitHub Actions, `moon check`, `moon test`, `moon info`, `moon fmt`, and `moon run`.
