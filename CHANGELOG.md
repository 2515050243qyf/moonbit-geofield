# Changelog

## 0.1.0

- Added geospatial core records: `GeoPoint`, `FieldSample`, `Grid`, `ProfileSample`, `HarmonicTerm`, and `SphericalHarmonicModel`.
- Added gravity helpers for normal gravity, free-air anomaly, and Bouguer anomaly.
- Added approximate magnetic declination, inclination, and component conversion.
- Added compact spherical harmonic evaluation.
- Added regular-grid nearest and bilinear sampling, plus transect profile extraction.
- Added CSV parsing and CSV/GeoJSON export helpers.
- Added demonstration CLI, checked README examples, and GitHub Actions workflows.
